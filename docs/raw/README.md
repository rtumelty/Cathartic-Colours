# Raw sources

The raw layer holds source material exactly as it was supplied: prototypes, planning notes, chat exports, and similar.

- **Immutable.** Read raw sources, never edit them. If a source is wrong or out of date, record that in a wiki page.
- **Summarised by the wiki.** Wiki pages summarise raw sources and cite them by source name and file path. Summaries must not replace the source.
- **Registered here.** Every source added to this folder gets a row in the register below, in the same commit.
